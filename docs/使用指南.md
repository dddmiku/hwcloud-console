# 使用指南

## 1. 目录

```
hwcloud-demo/
├── go/
│   ├── cmd/ internal/          源码
│   └── third_party/            playwright-go 1.61 客户端（源码）
├── data/                       示例内容
├── state/                      登录后生成会话（初始只有 README）
└── docs/
```

以下命令默认在 `hwcloud-demo\go` 目录执行。

## 2. 环境要求

- Windows x64
- Go 1.23+
- Google Chrome（推荐）；未安装时可安装 Playwright Chromium
- Playwright 1.61 driver（不随包提供，见下一节）

## 3. 构建

```bat
cd hwcloud-demo\go
go build -trimpath -o bin\hwcloud.exe ./cmd/hwcloud
```

首次构建会下载 Go 依赖（`go-ieproxy` 等）。构建完成后生成 `bin\hwcloud.exe`。

## 4. 安装 Playwright driver

driver 不随包提供。首次运行浏览器命令时，程序会尝试自动下载 1.61 版 driver。若自动下载失败，任选一种方式：

### 方式 A：用包内客户端安装

```bat
cd hwcloud-demo\go\third_party\playwright-go
go run ./cmd/playwright install chromium
```

该命令会下载 driver 和 Chromium。已有系统 Chrome 时，Chromium 可以不装，只下载 driver：

```bat
go run ./cmd/playwright --version
```

### 方式 B：复用已有 driver

找到任意 Playwright 1.61.x 的 driver 目录（应包含 `node.exe` 和 `package\cli.js`），例如 Python 安装：

```
C:\Users\<you>\AppData\Local\Programs\Python\Python312\Lib\site-packages\playwright\driver
```

设置环境变量后运行：

```bat
set PLAYWRIGHT_DRIVER_PATH=C:\Users\<you>\AppData\Local\Programs\Python\Python312\Lib\site-packages\playwright\driver
bin\hwcloud.exe check
```

## 5. 首次登录华为云

```bat
bin\hwcloud.exe login
```

- 弹出 Chrome 窗口，登录自己的华为云账号（密码 / 短信 / 扫码均可）。
- 脚本每 3 秒探测一次登录态，成功后保存 cookie 到 `..\state\cookies.json`。
- 已有有效 cookie 时会直接复用，不会重复要求登录。

验证：

```bat
bin\hwcloud.exe check
```

## 6. 自动签到

```bat
bin\hwcloud.exe sign
```

已签到时会输出「今日已签到，无需重复签到」。

## 7. 任务查询

```bat
bin\hwcloud.exe tasks --stars 1,2
```

`degree` 对应星级；`is_finish=1` 表示当前周期已完成。

## 8. 云实验（1 星「每周实践一个实验」）

```bat
bin\hwcloud.exe lab --dry-run
bin\hwcloud.exe lab
```

流程：

1. 打开实验详情（默认实验 ID 2325，ECS 入门实验）。
2. 点击「开始实验」，等待控制台窗口。
3. 截取控制台画面，填写过程记录并粘贴截图。
4. 点击「结束实验」释放环境。

注意：

- 会占用当日免费实验名额；名额用完后可能消耗实验点。
- 默认执行结束实验；`--keep` 可保留环境，但请自行释放。
- 过程记录默认读取 `..\data\lab_record.txt`；`--record-file` 可指定其他文件；`--lab-id` 可指定其他实验。

## 9. 博客（2 星「每日发布文章」）

编辑 `..\data\blog_post.md`，然后：

```bat
bin\hwcloud.exe blog --dry-run
bin\hwcloud.exe blog
```

说明：

- 标题取文件首行 `# 标题`，摘要自动取正文首段；可用 `--title` / `--summary` 覆盖。
- 首行 `# 标题` 只用于生成标题，不会重复写入正文。
- 标签由系统根据正文自动匹配，不能手动添加。
- 脚本会自动勾选「声明」复选框，否则「发表」按钮不可用。
- 发布后需要平台审核，成长任务可能延迟计入。
- 只保存草稿：`bin\hwcloud.exe blog --draft`。

## 10. GitCode Issue（2 星「每周给代码仓提 Issue」）

前置条件：先在 AI Agent 开发实践中心绑定自己的 GitCode 账号
（`https://hands-on-agent.developer.huaweicloud.com/#tasks`）。

```bat
bin\hwcloud.exe login-gitcode
bin\hwcloud.exe issue --dry-run
bin\hwcloud.exe issue
```

说明：

- `login-gitcode` 打开 GitCode 登录页，脚本被动检测 localStorage，不刷新页面。
- Issue 内容在 `..\data\issue_feature.md`，首行 `# 标题` 作为标题，正文按四个分节填写；`--title` 可覆盖。
- 默认「功能建议」模板；`--template bug` 可切换。
- 提交成功后返回 `iid` 和 Issue 地址。
- 成长任务由激励服务根据绑定的 GitCode 账号判定，通常有短暂延迟。

## 11. 定时任务（可选）

每天 09:00 签到示例：

```bat
schtasks /Create /SC DAILY /TN "HWCloudSign" ^
  /TR "\"D:\hwcloud-demo\go\bin\hwcloud.exe\" sign" /ST 09:00
```

程序会从 exe 所在目录向上查找 `data/`，不依赖当前工作目录。会话过期时任务会失败，需要手动执行一次 `login`。

## 12. 故障排查

| 现象 | 处理 |
| --- | --- |
| `未登录或登录态已过期` | 重新执行 `bin\hwcloud.exe login` |
| `404 no Route matched` | 检查系统代理；Go 版读取 Windows 系统代理，也可设置 `HTTPS_PROXY` |
| `please install the driver` | 按第 4 节安装 driver，或设置 `PLAYWRIGHT_DRIVER_PATH` |
| 浏览器打不开 / Chrome 未找到 | 安装 Google Chrome，或安装 Playwright Chromium |
| 任务提交成功但未计入 | 激励服务同步有延迟，等待几分钟后重新 `check` |
| 页面元素找不到 | 站点改版，需要更新选择器或接口；先用 `--dry-run` 定位 |

## 13. 安全与合规

- `state/` 保存登录会话和浏览器 profile，**不要分享、不要提交仓库**。
- 博客和 Issue 是公开内容，请确认内容真实、合规、非重复。
- 保持正常使用频率，避免高频请求触发风控。
- 脚本不绕过验证码、不破解登录；首次登录必须由账号本人在浏览器中完成。
- 仅在你拥有或已获授权的账号上使用。
