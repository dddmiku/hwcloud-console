# 华为云登录协议逆向记录

## 结论摘要

纯协议登录**部分打通**：前 4 步（拿到 `pageToken` / `sid`）已完全实现并验证，
第 5 步（提交账密）被服务端的页面绑定机制挡住。

## 完整链路（经抓包验证）

```
1. GET  auth.huaweicloud.com/authui/login.html?service=...
2. GET  auth.huaweicloud.com/authui/getSDKBaseInfo?flowType=unionLogin&service=...&site=mainland
        → pageToken / pageTokenKey / state / hwidConfig
3. GET  auth.huaweicloud.com/authui/isLogin
4. POST id1.cloud.huawei.com/UnifiedIDMPortal/ajaxHandler/common/getAgreementContent
        → 下发 JSESSIONID（Path=/UnifiedIDMPortal）
5. POST .../common/dev  (带 fp)
        → 返回 sid，这个 sid 就是 hwid_cas_sid
6. POST .../login/unionLoginByPwd
        → 提交账号密码
7. POST .../login/getSMSCodeV3
        → 发送短信验证码
8. POST .../login/unionLoginByPwd (带 smsAuthCode)
        → 完成登录，返回 callbackURL
```

## 关键发现

### 1. pageToken 不需要浏览器生成

`getSDKBaseInfo` 的响应里直接给了：

```json
{
  "pageToken": "<PAGE_TOKEN>...",
  "pageTokenKey": "<PAGE_TOKEN_KEY>",
  "state": "<CAS_STATE>",
  "transactionID": "<TRANSACTION_ID>",
  "hwidConfig": "%7B%22appID%22..."
}
```

源码依据（`app.bundle.js`）：

```js
getSDKBaseInfo.then(function(n) {
  var i = {
    pageTokenKey: n.pageTokenKey,   // 直接来自响应
    pageToken: n.pageToken,
    state: n.state,
    hwidConfig: n.hwidConfig
  };
```

### 2. fp 可以复用

`common/dev` 需要 `fp`（826 字符的浏览器指纹）。实测：

| 测试 | 结果 |
|---|---|
| 旧 fp + 旧 token（跨会话） | ✅ isSuccess:1，返回 sid |
| 旧 fp + 新 localStorageID | ✅ isSuccess:1，返回 sid |

`fp` **不绑定会话、不校验时效**。从浏览器抓一次存 `state/fp_cache.txt`，
之后所有纯协议请求都能用同一个值。

### 3. hwid_cas_sid 就是 common/dev 返回的 sid

```
common/dev 返回:  sid = <HWID_CAS_SID>
unionLoginByPwd:  hwid_cas_sid = <HWID_CAS_SID>
```

完全相同（84 字符）。

### 4. JSESSIONID 的 Path 不是 /

```
Set-Cookie: JSESSIONID=314EA2F3...; Path=/UnifiedIDMPortal; Secure; HttpOnly
```

查询 cookie jar 时必须用 `Path: "/UnifiedIDMPortal"`，用 `/` 查不到。

### 5. hwmeta 也是静态的

`unionLoginByPwd` 带 1356 字符的 `hwmeta`（base64），同样可以缓存复用。

## 未打通的部分

### 阶段一：二次验证（已突破）

`unionLoginByPwd` 返回 `10002080` 不是错误，是**要求二次验证**：

```json
{
  "errorCode": "10002080",
  "errorDesc": {
    "authCodeSentList": [
      {"accountType":-1, "name":"HONOR V30 PRO", "sent":1, "type":"device"},
      {"accountType":6,  "name":"157******41", "sent":0},
      {"accountType":5,  "name":"******7274@**.com", "sent":0},
      {"accountType":1,  "name":"*******0126@*****cqut.edu.cn", "sent":0}
    ],
    "riskFlag": "001000000011111101000010000",
    "extInfo": "FAD1739B...:A0AA18C6..."
  }
}
```

`accountType` 含义：`-1`=设备、`6`=短信、`5`=邮箱、`1`=其他邮箱。

验证码提交接口是 **`common/chkAuthCode`**（不是 `login/chkAuthCode`）。

### 阶段二：图片验证码风控（当前阻塞）

多次尝试后服务端返回：

```json
{"errorCode":"10000706","errorDesc":"{\"errorDesc\":\"need picture authcode risk\",...}"}
```

`10000706` = 图片验证码风控。触发原因：短时间内多次请求同一账号的登录接口。

这一步需要人眼看图输入，纯协议无法通过。但它是**风控触发后才出现**的，
正常频率下不会遇到。

### 已验证可用的接口

| 接口 | 用途 | 状态 |
|---|---|---|
| `common/getAgreementContent` | 建立 JSESSIONID | ✅ |
| `common/dev` | 用 fp 换 sid | ✅ |
| `login/getLoginIdsByPwd` | **验证密码**（只读，不登录） | ✅ 返回账号信息 |
| `login/getSMSCodeV3` | **发送短信验证码** | ✅ isSuccess:1 |
| `login/unionLoginByPwd` | 提交账密 | ✅ 触发二次验证 |
| `common/chkAuthCode` | 提交验证码 | ⚠️ 需 `authOprType` 参数 |

### getLoginIdsByPwd 的实际返回

```json
{
  "accountInfoList": [{
    "anonymousAccount": "d****ku",
    "anonymousEncryption": "eyJhbGciOiJIUzUxMiIsInR5cCI6IkpXVCJ9...",
    "avatar": "https://upfile-drcn.platform.hicloud.com/FileServer/image/..."
  }]
}
```

`anonymousEncryption` 是一个 JWT，payload 里含 `did`（设备 ID）和 `cat`（时间戳）。
这个值要传给 `unionLoginByPwd` 的 `anonymousLoginID`。

### 关键参数清单（chkAuthCode）

从 SDK 源码 `dealUpdatePassword` 反推：

```js
e.twoStepVerifyCode && (
  n.tipsSceneID = e.tipsSceneID,
  n.twoStepVerifyCode = e.twoStepVerifyCode,
  n.verifyUserAccount = e.verifyUserAccount,
  n.verifyAccountType = e.verifyAccountType,
  n.opType = e.mixinOptypeEnum.OPTYPE6_VERIFICATION  // = 6
)
```

服务端还要求 `authOprType`（SDK 里没有，是服务端参数），值待确认。

## 已实现的功能

### 1. `hwcloud verify-pw` —— 纯协议验证密码

```bash
hwcloud verify-pw --account <ACCOUNT_A> --password 'xxx'
```

```json
{
  "stage": "getLoginIdsByPwd",
  "message": "密码正确",
  "username": "d****ku"
}
```

走 `login/getLoginIdsByPwd`，**只读接口**，不产生登录动作、不触发登录风控。
可以用来确认密码是否正确。

### 2. `hwcloud send-sms` —— 纯协议发送短信验证码

```bash
hwcloud send-sms --account <ACCOUNT_A> --password 'xxx'
```

```json
{
  "stage": "getSMSCodeV3",
  "need_sms": true,
  "message": "短信已发送（上次发送码 10001057）"
}
```

注意：必须先过 `getLoginIdsByPwd`，否则 `getSMSCodeV3` 会报
`10000004 session is invalid`。

### 3. `hwcloud pure-login` —— 登录（到二次验证为止）

```bash
hwcloud pure-login --account <手机号> --password <密码>
```

能拿到 `sid` 并触发二次验证，但受图片风控限制，最后一步需要人工。
